# Examples

Sample outputs from running the `generate-docs` skill on a project. The actual `docs/*.md` files are
generated fresh from your codebase each run — these show what the **context-file integration** and
**verification report** look like.

| Example | Description |
|---------|-------------|
| [claude-md-example.md](claude-md-example.md) | The auto-generated section appended to your CLAUDE.md, with progressive-disclosure references |
| [agents-md-example.md](agents-md-example.md) | The AGENTS.md file created for cross-tool compatibility |
| [verification-report-example.md](verification-report-example.md) | A sample `_verification_report.md` showing A–F grading and actionable feedback |
